# AI Video Generator

GitHub + Vercel starter for a Text-to-Video website.

## Deploy
1. Upload these files to a new GitHub repository.
2. Import the repository into Vercel.
3. Deploy.
4. The website will work in Demo Mode.
5. Add a real AI video provider API inside `api/generate.js`.

## Important
Never put an API key in `index.html` or `app.js`.
Use Vercel Environment Variables instead.
